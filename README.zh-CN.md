# alonabot-plugin-template

[English](README.md)

AlonaBot 插件起点，包含 hello 命令、配置、集成测试与五平台发布工作流。

## 快速使用

通过[使用此模板](https://github.com/new?template_owner=AlonaBot&template_name=alonabot-plugin-template)创建仓库，再按[模板替换指南](docs/template-setup.zh-CN.md)设置身份。以下安装来源为生成后仓库的占位。

```fish
alonabot install --source owner/alonabot-plugin-template
```

启用生成后的插件，发送 `/hello Alona`。
