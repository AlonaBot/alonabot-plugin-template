# alonabot-plugin-template

[简体中文](README.zh-CN.md)

A starting point for AlonaBot plugins, with a hello command, configuration, integration test, and five-platform release workflow.

## Quick start

Create a repository with [Use this template](https://github.com/new?template_owner=AlonaBot&template_name=alonabot-plugin-template), then follow [template setup](docs/template-setup.md). The installation source below is a placeholder for the generated repository.

```fish
alonabot install --source owner/alonabot-plugin-template
```

Enable the generated plugin and send `/hello Alona`.
